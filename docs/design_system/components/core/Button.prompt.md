One-sentence: TrainerFlow's pill-shaped action button — a glowing lime gradient for primary CTAs, muted dark/ghost variants elsewhere.

```jsx
<Button variant="primary" size="lg">Start Free Trial</Button>
<Button variant="ghost">See How It Works</Button>
```

Variants: `primary` (lime gradient + glow), `secondary` (raised charcoal), `ghost` (hairline outline), `dark` (near-black pill for nav). Sizes: `sm` `md` `lg`. Props: `href` (renders `<a>`), `leadingIcon`/`trailingIcon`, `disabled`, `fullWidth`. Always fully rounded.
