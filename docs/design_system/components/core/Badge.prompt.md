One-sentence: Rounded pill label used for section eyebrows and inline status chips.

```jsx
<Badge tone="lime">The Solution</Badge>
<Badge tone="solid" dot={false}>Popular</Badge>
```

Tones: `neutral` (hairline chip, default), `lime` (tinted), `solid` (lime gradient fill). A leading status `dot` shows by default; pass an `icon` to replace it.
